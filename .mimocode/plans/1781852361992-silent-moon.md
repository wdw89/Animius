## Content

### Build & Run Commands
- Debug build: `./gradlew assembleDebug`
- Release build: `./gradlew assembleRelease` (requires env vars)
- Unit tests: `./gradlew test`
- Single test class: `./gradlew :app:testDebugUnitTest --tests "com.lanlinju.animius.FooTest"`
- No lint, typecheck, or formatter configured — skip lint/typecheck steps
- JVM target: 17, AGP 8.11.0, Kotlin 2.2.0

### Secrets & Environment
- `DANDANPLAY_APP_ID` and `DANDANPLAY_APP_SECRET` read from env vars (not local.properties) at build time into BuildConfig
- Signing keys (`KEY_STORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`) also from env vars
- Without these env vars, build succeeds but danmaku features are non-functional

### Module Structure
- `:app` — main application (MVVM + Clean Architecture)
- `:video-player` — Compose Media3 ExoPlayer wrapper
- `:download` — download engine (OkHttp, supports M3U8/range)
- `:danmaku` — Compose danmaku overlay engine

### Architecture Quick Reference
- Source code under `app/src/main/java/com/lanlinju/animius/`
- Layers: `data/` → `domain/` → `presentation/`
- Multi-source anime scraping via `AnimeSource` interface + `SourceHolder` singleton (11 sources, enum `SourceMode`)
- DI: Hilt with `@HiltAndroidApp`, `@AndroidEntryPoint`, `@HiltViewModel`
- Navigation: type-safe Compose Navigation with `@Serializable` sealed class routes
- State: `MutableStateFlow<Resource<T>>` pattern, no MVI
- Domain model conversions are extension functions on data classes (not separate mapper files)

### Key Conventions
- Screens: `{Feature}Screen.kt` + `{Feature}ViewModel.kt` in `presentation/screen/{feature}/`
- DTOs: `*Bean.kt` suffix
- Entities: `*Entity.kt`, DAOs: `*Dao.kt`
- Sources: `{Name}Source.kt` in `data/remote/parse/`
- Images via Coil, JSON via kotlinx.serialization
- Room schema exported to `app/schemas/` via KSP

### Gotchas
- No linting/static analysis configured (no detekt, ktlint, lint.xml)
- No lockfiles — dependency resolution not reproducible
- Room uses `fallbackToDestructiveMigration()` — schema changes wipe data
- Release build has R8 minification — keep rules in `app/proguard-rules.pro`
- `SourceMode` enum kept in ProGuard (serialized to SharedPreferences as string)
- WebView-based sources (Xifan, Ntdm, Gugufan) need special handling via `WebViewUtil`

### CI
- GitHub Actions on push to `main`/`feat-compat-tv`, PRs, and tags
- CI only builds — no tests run in CI
- Release workflow triggers on `v*` tags
