## 问题

1. **WeekScreen TabRow** (`WeekScreen.kt:165-175`): Material3 `Tab` 指示器是底部线条，聚焦时无圆角矩形背景
2. **HomeScreen 站源文本** (`HomeScreen.kt:413-427`): 纯 `Text`，无焦点样式，点击无反应
3. **HomeScreen GridLayoutTabs** (`HomeScreen.kt:224-230`): 自定义 `Tab` 用 `Surface(RoundedCornerShape(11.dp))`，聚焦有背景但非统一风格

## 方案

### 核心思路

Material3 `Tab` 内置 onClick + focus，但指示器是线条不是圆角矩形。用 `Surface(onClick, shape, color)` 包一层即可获得圆角矩形背景 + 内置 focusable，无需单独建组件。

### 1. 修改 WeekScreen (`WeekScreen.kt:165-175`)

**改前:**
```kotlin
TabRow(selectedTabIndex = pagerState.currentPage) {
    TABS.forEachIndexed { index, title ->
        Tab(text = { Text(text = title) }, ...)
    }
}
```

**改后:**
```kotlin
Row(
    modifier = Modifier.fillMaxWidth().padding(horizontal = 16.dp),
    horizontalArrangement = Arrangement.spacedBy(8.dp),
) {
    TABS.forEachIndexed { index, title ->
        Surface(
            onClick = { scope.launch { pagerState.scrollToPage(index) } },
            shape = RoundedCornerShape(20.dp),
            color = if (pagerState.currentPage == index)
                MaterialTheme.colorScheme.primary
            else Color.Transparent,
            contentColor = if (pagerState.currentPage == index)
                MaterialTheme.colorScheme.onPrimary
            else MaterialTheme.colorScheme.onSurface,
        ) {
            Text(
                text = title,
                modifier = Modifier.padding(horizontal = 16.dp, vertical = 8.dp),
            )
        }
    }
}
```

### 2. 修改 HomeScreen GridLayoutTabs (`HomeScreen.kt:224-230`)

### 3. 修改 HomeScreen 站源选择器 (`HomeScreen.kt:413-427`)
